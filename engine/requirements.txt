# --- still runtime, and the reason torch has not left yet --------------------
#
# torch is ~2-3GB installed on Windows and exists here for ONE consumer:
# regions.py loads MobileSAM through the `mobile_sam` package for pixel_color's
# material anchors. abpn.py used to be the other consumer and no longer is --
# it runs on onnxruntime, gated by test_onnx_parity.py (measured: 4.1e-06 at
# the network, worst 1/255 on the finished image).
#
# Exporting MobileSAM is what lets both lines below go, and with them the
# install-from-github, which needs git on the build machine and breaks if the
# upstream repo moves.
#
# CAREFUL: regions.py:130-133 swallows the load failure and returns zero
# regions. Dropping torch before the export lands would not raise -- pixel_color
# would quietly lose its material anchors. Export first, measure, then delete.
torch
mobile_sam @ git+https://github.com/ChaoningZhang/MobileSAM.git
